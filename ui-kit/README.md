# suimon UI kit

ワークフローと実行履歴を表示する React + TypeScript のコンポーネント集です。

バックエンドの言語や通信方式が変わっても再利用できるよう、通信・実行・エラー処理は組み込み先に任せます。画面構成も用途に合わせて変えられるよう、各部品を独立して利用できる形にしています。

利用例は [Go example UI](../implementations/go/example/ui/src/)、起動方法は [example の README](../implementations/go/example/README.md) を参照してください。
